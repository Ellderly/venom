Записи звуков для игры. Чего здесь нет — игра синтезирует сама.

Обычный способ — импорт из репозитория warfront:

    python3 tools/import_sounds.py ПУТЬ_К_warfront

Скрипт копирует нужные файлы сюда и пишет manifest.json:

    { "слот": ["файл1.ogg", "файл2.ogg"], ... }

Слоты (несколько файлов в слоте — случайный выбор варианта):
  geran_near      мотор «Герани-2» вблизи, ровный отрезок, зацикливается
  geran_far       мотор «Герани-2» вдали (над городом), зацикливается
  explosion_near  взрыв вблизи
  explosion_far   взрыв вдали
  debris          падающие обломки
  siren           сирена воздушной тревоги

Новый юнит: добавьте слоты в SLOTS в tools/import_sounds.py и сошлитесь на них в src/units.ts (поле sounds).
Можно положить файлы и вручную (ogg, mp3, wav) и дописать их в manifest.json.
