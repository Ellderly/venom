Сюда можно положить настоящие записи звуков — игра возьмёт их вместо синтезированных.

1. Положите файлы в эту папку (mp3, ogg или wav).
2. Перечислите их в list.json, например:
   { "geran": "geran.mp3", "explosion": "explosion.ogg", "siren": "siren.mp3" }

geran      — звук мотора, ровный отрезок 2–10 секунд, будет зациклен
explosion  — одиночный взрыв
siren      — сирена воздушной тревоги
